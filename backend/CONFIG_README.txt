============================================
Meeting Assistant - 設定ガイド
============================================

このフォルダには Meeting Assistant の設定ファイルが格納されます。

--------------------------------------------
フォルダ構成
--------------------------------------------

  config/
  ├── .env                 ... メイン設定ファイル
  ├── creds.json           ... Google Calendar 認証情報 (オプション)
  ├── meeting_assistant.db ... データベース (自動作成)
  └── CONFIG_README.txt    ... このファイル

--------------------------------------------
1. 基本設定 (.env)
--------------------------------------------

.env ファイルをテキストエディタで開き、以下を設定してください:

  OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx

  - Whisper API モードまたはリサーチ機能を使う場合は必須です
  - https://platform.openai.com/api-keys から取得

  WHISPER_MODE=local
  - "local": オフライン文字起こし (GPU推奨)
  - "api": OpenAI Whisper API を使用 (要APIキー)

--------------------------------------------
2. Google Calendar 連携 (オプション)
--------------------------------------------

Google Calendar から現在の会議名を自動取得できます。

  1. Google Cloud Console でサービスアカウントを作成
  2. Calendar API を有効化
  3. JSON キーファイルをダウンロード
  4. このフォルダに "creds.json" として配置
  5. .env ファイルで以下を設定:
     GOOGLE_SERVICE_ACCOUNT_FILE=creds.json
  6. Google Calendar の共有設定でサービスアカウントの
     メールアドレスに閲覧権限を付与

--------------------------------------------
3. データの保存先
--------------------------------------------

  - データベース: この config フォルダ内に自動作成されます
  - 会議ログ: ~/Documents/MeetingLogs (設定画面で変更可)
  - ログファイル: (アプリデータフォルダ)/logs/
